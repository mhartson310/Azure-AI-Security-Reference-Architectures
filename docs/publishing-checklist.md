# Publication / validation checklist

- [ ] Verify product names, feature claims, SKU, region, licensing and preview/GA status.
- [ ] Identify each sensitive data path and its actual authorization enforcement point.
- [ ] Validate conditional access, identity scopes, permission revocation and negative-security tests.
- [ ] Distinguish Purview data governance from application/runtime enforcement.
- [ ] Validate cost baselines; do not claim arbitrary savings percentages.
- [ ] Record test setup, expected versus actual results, limitations, sanitized evidence and review date.
- [ ] Proofread diagrams at full size and thumbnail size.
- [ ] Never expose tenant identifiers, keys or confidential user data.
